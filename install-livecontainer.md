# Installing LiveContainer
1. Add the LiveContainer (nightly) AltSource to SideStore by clicking [this link](https://intradeus.github.io/http-protocol-redirector?r=sidestore://source?url=https://github.com/LiveContainer/LiveContainer/releases/download/nightly/apps_nightly.json) on your device.
2. Install LiveContainer (nightly) from the AltSource (If it asks about App IDs, pick the top option).
3. Ensure LiveContainer isn't hidden from your home screen, then navigate to Settings → Import JIT-Less Certificate from SideStore. When you see a prompt from SideStore, select "Export".
4. Scroll down, and set "JIT enabler" to "StikDebug".
5. Legally download your desired apps' .ipa's (GitHub is usually a good source for them). Navigate to Apps, and install your apps to LiveContainer using the "+" button in the top-left.
6. Double-tap all apps and toggle "Fix File Picker" on. For apps that require JIT, also toggle "Launch with JIT" on.
