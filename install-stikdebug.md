# Installing StikDebug
1. Add the StikDebug AltSource to SideStore [here](https://intradeus.github.io/http-protocol-redirector?r=sidestore://source?url=https://stikdebug.xyz/index.json).
2. Install StikDebug from the AltSource by selecting "FREE".
3. Open StikDebug's Settings, then import your pairing file from `On My iPhone/iPad → SideStore → ALTPairingFile.mobiledevicepairing`.
