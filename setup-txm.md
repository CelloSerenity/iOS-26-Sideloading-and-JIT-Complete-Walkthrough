# Set up StikDebug (TXM)
1. Navigate to StikDebug → Settings and toggle all switches on.
2. In LiveContainer, double-tap your app that requires JIT.
3. Ensure "Launch with JIT" is toggled on, then tap "Select".
4. Select the script that matches the your apps name from `On My iPhone/iPad → StikDebug → scripts` folder (it should be a .js file). If your app's name isn't listed, it does not support JIT on iOS 26.
